# Do-Hook-In - Frontend

זהו קובץ ה-README של צד הלקוח. כאן נציג בגדול כיצד ממשק המשתמש יהיה בנוי.
נעבוד לפי פיצ'רים שנבנה אחד אחרי השני.

---

## מבנה הפיצ'רים

### 1. 🏠 דף הבית
דף נחיתה כללי המציג את המערכת ומאפשר ניווט להתחברות או רישום.

### 2. 📝 דף רישום
טופס רישום לפי סוג משתמש - מנהל מחסן, ספק, או סיטונאי.

### 3. 🔐 דף התחברות
התחברות למערכת עם JWT, עם הפניה אוטומטית לממשק המתאים לפי סוג המשתמש.

### 4. 🏭 ממשק מנהל מחסן (Logistics Manager)
- **דשבורד מרכזי** - תצוגת סטטוס כללית של המחסן
- **ניהול הזמנות** - מעקב אחר הזמנות נכנסות ויוצאות
- **ניהול מלאי** - צפייה ועדכון מוצרים במחסן
- **ניהול ספקים** - רשימת ספקים פעילים וניהולם
- **ניהול סיטונאים** - רשימת סיטונאים פעילים וניהולם
- **ניהול משלוחים ורכישות** - מעקב אחר משלוחים מחו"ל
- **התראות והודעות** - הגדרת אירועי התראה וצפייה בהתראות
- **דוחות וחשבוניות** - יצירת דוחות וחשבוניות לפי הזמנה
- **בקרת משתמשים** - ניהול הרשאות וחשבונות משתמשים
- **הגדרות מערכת** - קונפיגורציה כללית של המערכת

### 5. 🚚 ממשק ספק (Supplier)
- **דשבורד** - תצוגה כללית של המשלוחים הפעילים שלו
- **ניהול משלוחים** - דיווח על משלוח בתהליך ועדכון מיקומו
- **היסטוריית משלוחים** - צפייה בנתוני משלוחים קודמים (כמויות, קיבולת
  מכולות, עלויות) לצורך השוואה וקבלת החלטות לוגיסטיות למשלוח הנוכחי
- **ניהול עלויות** - הוספת חיובים נוספים לחשבון הסופי של המחסן, תוך
  התחשבות בנתוני קיבולת וכמויות
- **התראות** - צפייה בהתראות רלוונטיות (למשל כשמשלוח עבר עיבוד מלא)

### 6. 🛒 ממשק סיטונאי (Vendor)
- **דשבורד** - תצוגה כללית של ההזמנות הפעילות שלו
- **קטלוג מוצרים** - עיון במוצרים הזמינים במחסן
- **הגשת הזמנה** - יצירת הזמנה חדשה עם פירוט עלויות
- **מעקב הזמנות** - צפייה בסטטוס כל הזמנה לאורך מחזור החיים שלה
- **מחשבון כדאיות** - טופס שבו הסיטונאי מזין ומעדכן את הנתונים שלו
  (עלויות אחסון, עלויות משלוח לפיזור, ביקושים צפויים) ומריץ חישובים כדי
  להחליט האם כדאי לו לפזר סחורה לחנויות, לאחסן חלק, או להשאיר הכל במחסן
  היבואן
- **התראות** - צפייה בהתראות רלוונטיות (למשל כשמוצרים בעיבוד)

### 7. 📬 יצירת קשר
טופס פנייה למנהלי המערכת.

### 8. 📄 תקנון ופרטים על המערכת
תנאי שימוש ומידע כללי על הפלטפורמה.

---

## הערות
- הממשק בנוי כ-SPA עם React
- ניתוב בין דפים עם React Router
- ניהול סטייט עם Redux ו-Context API
- תקשורת עם השרת דרך Axios
